# SardiniaCraft AI — Laboratorio Artistico — CLAUDE.md

## Progetto
Copilota AI per artigianato sardo d'eccellenza. Backend FastAPI con chatbot AI per supportare artigiani nella gestione del laboratorio, catalogo prodotti e comunicazione clienti.

## Stack
- **Backend:** Python, FastAPI, Uvicorn
- **CORS:** abilitato (sviluppo locale)

## Struttura
```
app.py          # Server principale FastAPI
index.html      # Frontend
requirements.txt
```

## Comandi
```bash
pip install -r requirements.txt
uvicorn app:app --reload    # Dev server (localhost:8000)
```
